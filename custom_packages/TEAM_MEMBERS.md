# Team Package Ownership

Each teammate should place their ROS 2 packages inside their own directory:

```text
custom_packages/<team-member>/<package-name>/
```

Current team directories:

```text
custom_packages/
├── aaron/
├── brendan/
├── chris/
├── ethan/
├── jose/
├── joshua/
├── manuel/
├── marcos/
├── muhammad/
├── pablo/
└── ricardo/
```

Use lowercase directory names for consistency. The ROS package name inside each package must also be unique.

Example:

```text
custom_packages/marcos/wall_follow/
custom_packages/ricardo/safety_controller/
```
